## repositorio


Este repositorio ha sido elaborado como material de aprendizaje sobre:

- Git.
- GitHub.
- Sistemas de control de versiones.
- Repositorios.
- Ramas.
- Commits.
- Push.
- Pull Request.
- Merge.
- Markdown.

## Objetivo

El objetivo de este repositorio es organizar y presentar de forma clara
los principales conceptos relacionados con Git y GitHub estudiados en
la unidad.
