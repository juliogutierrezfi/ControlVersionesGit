# Lenguaje de marcas: Markdown

## ¿Qué es Markdown?

**Markdown** es un lenguaje de marcas ligero que permite dar formato a un texto de una forma sencilla utilizando diferentes símbolos y caracteres.

Se utiliza principalmente para crear documentación, archivos `README`, apuntes y páginas web.

## ¿Para qué sirve Markdown?

Markdown permite:

- Crear títulos y subtítulos.
- Escribir texto en **negrita** o *cursiva*.
- Crear listas.
- Añadir enlaces e imágenes.
- Crear tablas.
- Insertar bloques de código.
- Organizar la información de forma clara y sencilla.
