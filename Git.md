# Sistemas de control de versiones: Git

## ¿Qué es Git?

**Git** es un sistema de control de versiones que permite registrar, guardar y gestionar los cambios que se realizan en los archivos de un proyecto.

Su principal objetivo es poder **controlar las diferentes versiones de un proyecto** y saber qué cambios se han realizado, cuándo y quién los ha realizado.

## ¿Para qué sirve Git?

Git sirve principalmente para:

- Guardar los cambios realizados en un proyecto.
- Recuperar versiones anteriores de los archivos.
- Trabajar en equipo sin perder los cambios de otros compañeros.
- Crear diferentes ramas para trabajar en nuevas funciones.
- Comparar los cambios realizados entre diferentes versiones.

## ¿Cómo funciona Git?

Git guarda los cambios mediante **commits**. Un commit es como una captura del estado del proyecto en un momento determinado.

Por ejemplo:

```bash
git add .
git commit -m "Añadida nueva función"
