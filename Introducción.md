# Introducción

En este tema aprenderemos los conceptos básicos de **Git**, **Markdown** y **GitHub**, herramientas muy utilizadas en el desarrollo de proyectos y en el trabajo en equipo.

# 1. Sistemas de control de versiones: Git

**Git** es un sistema de control de versiones que permite registrar y gestionar los cambios realizados en los archivos de un proyecto. Gracias a Git, podemos volver a versiones anteriores y trabajar con otras personas de forma organizada.

# 2. Lenguaje de marcas: Markdown

**Markdown** es un lenguaje de marcas sencillo que permite dar formato a un documento utilizando diferentes símbolos. Por ejemplo, `#` se utiliza para crear títulos y `-` para crear listas. Es muy utilizado para escribir documentación.

# 3. Repositorio: GitHub

**GitHub** es una plataforma que permite almacenar repositorios de **Git** en Internet. También facilita el trabajo colaborativo, ya que varias personas pueden participar en un mismo proyecto y compartir sus cambios.

# 4. Conceptos básicos de Git/GitHub

Para trabajar con Git y GitHub es importante conocer conceptos como **repositorio**, **commit**, **branch**, **push**, **pull** y **clone**. Estos permiten guardar cambios, crear diferentes versiones y sincronizar nuestro proyecto con un repositorio remoto.
