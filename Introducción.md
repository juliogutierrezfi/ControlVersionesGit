# Introducción

En este tema aprenderemos los conceptos básicos de **Git**, **Markdown** y **GitHub**, herramientas muy utilizadas en el desarrollo de proyectos.

# 1. Sistemas de control de versiones: Git

**Git** es un sistema de control de versiones que permite guardar y gestionar los cambios realizados en un proyecto.

# 2. Lenguaje de marcas: Markdown

**Markdown** es un lenguaje de marcas sencillo que permite dar formato a textos mediante símbolos como `#`, `*` o `-`.

# 3. Repositorio: GitHub

**GitHub** es una plataforma que permite almacenar repositorios Git en Internet y colaborar con otras personas en diferentes proyectos.

# 4. Conceptos básicos de Git/GitHub

Aprenderemos conceptos y comandos básicos como **repositorio, commit, branch, push, pull y clone**, necesarios para trabajar con Git y GitHub.
