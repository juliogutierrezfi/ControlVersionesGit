# Introducción

En la actualidad, muchos proyectos informáticos se desarrollan de forma colaborativa, por lo que es necesario disponer de herramientas que permitan organizar y controlar los cambios realizados en los archivos.

Los **sistemas de control de versiones** permiten guardar un historial de las modificaciones realizadas en un proyecto y recuperar versiones anteriores cuando sea necesario.

Uno de los sistemas de control de versiones más utilizados es **Git**. Git permite registrar los cambios realizados en los archivos de un proyecto, crear diferentes versiones y trabajar de forma independiente sin perder el trabajo realizado por otros miembros del equipo.

Por otra parte, **GitHub** es una plataforma que permite almacenar repositorios que utilizan Git y facilita el trabajo colaborativo entre diferentes personas. Gracias a GitHub, varios usuarios pueden participar en un mismo proyecto, compartir sus cambios y revisar las modificaciones realizadas por otros compañeros.

En esta práctica se trabajará con **Git, GitHub y Markdown** para conocer los conceptos básicos del control de versiones y aprender a colaborar en un proyecto.

Para ello, se creará un repositorio llamado `ControlVersionesGit`, en el que cada integrante del grupo realizará una parte del trabajo.

Durante el desarrollo de la actividad se utilizarán diferentes conceptos, como los **repositorios**, los **commits**, los **forks**, las **ramas** y los **Pull Requests**.

El objetivo principal de esta práctica es aprender a utilizar **Git y GitHub** y comprender la importancia del control de versiones en el desarrollo de proyectos colaborativos.
