# Repositorio GitHub

## ¿Qué es GitHub?

GitHub es una plataforma web utilizada para alojar proyectos y código de desarrolladores.

Utiliza Git como sistema de control de versiones y permite almacenar tanto software como documentación.

Además, permite que diferentes desarrolladores colaboren en un mismo proyecto.

## ¿Qué es un repositorio?

Un repositorio es como una carpeta donde se encuentran almacenados los archivos de un proyecto.

En un repositorio podemos encontrar:

- Código.
- Documentación.
- Ejemplos.
- Archivos de configuración.
- Archivo README.
- Historial de cambios.

## Tipos de repositorios

Existen principalmente dos tipos:

### Repositorio público

Es visible para cualquier persona.

Permite consultar y descargar el contenido del proyecto.

### Repositorio privado

El acceso está restringido a determinados usuarios.

Se utiliza cuando el contenido del proyecto no debe ser público.

## Archivo README

El archivo `README.md` contiene información básica sobre el proyecto.

Puede incluir:

- Nombre del proyecto.
- Descripción.
- Créditos.
- Índice de contenidos.
- Instrucciones de uso.
- Licencia.
- Información adicional.

## Git y GitHub

Git y GitHub no son lo mismo.

**Git** es un sistema de control de versiones distribuido.

**GitHub** es una plataforma web que utiliza Git para alojar proyectos y facilitar la colaboración.

## Colaboración

GitHub permite que diferentes personas puedan trabajar sobre un mismo proyecto.

Los desarrolladores pueden crear ramas, realizar cambios y solicitar que estos cambios sean integrados en el proyecto principal mediante Pull Requests.

## Conclusión

Git permite controlar las diferentes versiones de un proyecto mientras que GitHub proporciona una plataforma donde alojar los proyectos y colaborar con otros desarrolladores.
